📌 ESSENTIAL SETUP (5 STEPS)
═══════════════════════════════════════════════════════════════

STEP 1️⃣: Install MySQL Database
─────────────────────────────────
Windows: Download from https://dev.mysql.com/downloads/installer/
Mac:     brew install mysql && brew services start mysql
Linux:   sudo apt install mysql-server

After installation, create the database:
  mysql -u root -p
  CREATE DATABASE lead_management;
  EXIT;


STEP 2️⃣: Get Hugging Face API Token (Free!)
─────────────────────────────────────────────
1. Go to https://huggingface.co/
2. Sign up (free)
3. Go to Settings → Access Tokens
4. Create new token (select "Read" access)
5. COPY the token!


STEP 3️⃣: Install Python Dependencies
──────────────────────────────────────
cd autonomous_lead_identifier
python -m venv venv

# Activate virtual environment:
Windows: venv\Scripts\activate
Mac/Linux: source venv/bin/activate

pip install -r requirements.txt


STEP 4️⃣: Configure Environment (.env file)
────────────────────────────────────────────
cp .env.template .env

Edit .env file with:
  DB_PASSWORD=your_mysql_password
  HF_API_TOKEN=your_token_from_step2


STEP 5️⃣: RUN THE PROJECT! 🚀
─────────────────────────────

Option A - Run Lead Collection:
  python main.py

Option B - View Dashboard:
  streamlit run dashboard.py
  (Opens browser at http://localhost:8501)

═══════════════════════════════════════════════════════════════
🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "Can't connect to MySQL"
   → Check MySQL is running
   → Verify password in .env file
   → Make sure database exists

❌ "Hugging Face API error"
   → Check your token is correct in .env
   → Verify internet connection
   → Free tier has rate limits (wait a few minutes)

❌ "Module not found"
   → Activate virtual environment first!
   → Run: pip install -r requirements.txt

❌ "Chrome driver error"
   → Make sure Chrome browser is installed
   → Internet connection required
